# 🚀 Desarrollo del TDH Engine con Vagrant

> **¡LIBERACIÓN DE DOCKER DESKTOP!** - Entorno estable y profesional para desarrollo

## 📋 Resumen

Este entorno Vagrant proporciona una máquina virtual Ubuntu 22.04 con **Docker nativo** (el de verdad) para desarrollar y ejecutar el TDH Engine sin los problemas de Docker Desktop en macOS.

## 🎯 Objetivo

Crear un entorno de desarrollo 100% reproducible, estable y profesional que:
- ✅ Elimina Docker Desktop del flujo de trabajo
- ✅ Proporciona Docker nativo en Linux
- ✅ Mantiene sincronización bidireccional con el host
- ✅ Incluye todas las herramientas SAST necesarias
